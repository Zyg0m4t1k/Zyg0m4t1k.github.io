## 📌 Description

The **Groupe** plugin lets you monitor the global state of a set of commands (e.g. multiple lights, shutters, alerts)
and display a **widget** in your Jeedom views with customizable **icons / images**.

---

## 📦 Installation

Like any Jeedom plugin:

1. Install from the Market (or via ZIP)
2. Activate the plugin
3. Go to **Plugins → Monitoring → Groupe**

---

## ⚙️ Configuration

### 1) Create a device

Create a new device by clicking **+**.

![Create device](/img/plugins/groupe/groupe5.png)

### 2) Device settings

- **Add a device**: select a device and its status commands, and (optionally) action commands if
  **Enable actions** is checked.
- **Invert**: if checked, the state (and therefore the icon/image) switches to **active** only if **all** devices are active.
- **Icon ON**: widget icon when at least 1 command is active.
- **Icon OFF**: widget icon when all commands are inactive.
- **Image ON**: widget image when at least 1 command is active.
- **Image OFF**: widget image when all commands are inactive.

> Tip: you can choose between **icon** (FontAwesome) or **image** depending on your preferred look.

---

## 🧾 Commands

![Commands](/img/plugins/groupe/groupe6.png)

The plugin exposes a simple widget behavior:

- If **no** device is active → click = **All ON** (activate all)
- If **at least one** device is active → click = **All OFF** (deactivate all)

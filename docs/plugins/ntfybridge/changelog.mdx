## 2026-10-19

* **Chat Famille** — messagerie privée entre membres du foyer, accessible depuis le navigateur ou installable sur l'écran d'accueil (PWA)
* Chat : notifications push par salon — muet par salon, icône cloche barrée dans la liste
* Chat : envoi de photos et fichiers — bouton trombone, coller depuis le presse-papier, glisser-déposer
* Chat : visionneuse d'images plein écran (swipe bas pour fermer sur mobile)
* Chat : boutons d'action ntfy affichés dans les messages (liens, confirmations Jeedom…)
* Chat : modification du serveur, de l'utilisateur et du mot de passe depuis les Réglages
* Chat : corrections de stabilité (annulation de dialogue, messages manqués en arrière-plan)

## 2026-07-24

* Corrections de sécurité et de robustesse (14 points)
* Interface d'écoute ntfy configurable : localhost uniquement ou réseau local
* Les scripts du mode secours sont reconnus automatiquement selon leur extension
* Node.js 22 requis ; vérification de l'intégrité du binaire ntfy à l'installation
* Commande `ping` secours : détecte aussi une coupure DNS ou VPN
* Nettoyage de l'interface

## 2026-06-20

* **Profils d'envoi nommés** — regroupez priorité, tags, icône et topic dans un profil réutilisable (`[profile=alerte]`)
* **Envoi de fichiers locaux** depuis un scénario Jeedom (commande `send_file`)
* **Réponses multi-valeurs** — insérez plusieurs commandes Jeedom dans le même message de réponse (`{#id#}`)
* Commandes `Déclencher réponse` et `Déclencher action` — déclenchement depuis un scénario
* Options d'envoi étendues : markdown, icône, délai, cache, firebase
* Mode silencieux par plages horaires, avec passage en priorité minimale plutôt que blocage total

## 2026-06-19

* **Assistant reverse proxy** — génère la configuration en 5 étapes guidées (Apache, Nginx, NPM, Traefik, Cloudflare)
* **Mode externe** — connexion à un serveur ntfy existant (ntfy.sh, auto-hébergé…)
* **Panel utilisateurs** — gestion des droits par topic depuis Jeedom (lecture/écriture, lecture seule, accès interdit)
* Détection automatique du port ntfy avec bouton de réinitialisation

## 2026-06-01

* **Confirmation Oui / Non** — avant d'exécuter une action, Jeedom envoie une notification avec deux boutons
* **Règles de réponse** — Jeedom répond automatiquement quand il reçoit un mot-clé
* Mode silencieux global par équipement
* Détection de mots-clés plus précise (évite les faux positifs)
* Première mise à disposition du plugin

# Plugin TaskLauncher

Le plugin **TaskLauncher** permet de créer des équipements temporels dans Jeedom pour déclencher automatiquement des **actions**, des **commandes** ou des **scénarios**.

Il permet notamment de gérer :

- ⏰ des **réveils**
- 🕒 des **horloges**
- 📅 des **événements programmés**
- ⏳ des **décomptes à partir d’une date**
- ⏱️ des **minuteurs en secondes** (démon Node.js)
- 🔔 des **rappels** avec compte à rebours et alertes d’urgence

---

## ✨ Vue d’ensemble

TaskLauncher peut être utilisé aussi bien pour de simples rappels que pour des automatisations plus avancées.

Exemples d’usage :

- lancer un scénario du matin à heure fixe
- afficher une horloge sur un design ou un dashboard
- programmer une action à une date précise
- déclencher une commande avec délai ou exécution ponctuelle

---

## ⚙️ Installation

L’installation se fait comme pour n’importe quel plugin Jeedom.

### 1️⃣ Installation depuis le Market

1. Installez le plugin depuis le Market Jeedom.
2. Activez le plugin.
3. Ouvrez la page du plugin dans :

```text
Plugins → Organisation → TaskLauncher et activer le plugin
```

### 2️⃣ Accès au plugin

Une fois le plugin activé, vous pouvez créer un nouvel équipement puis choisir son type.

![type](/img/plugins/TaskLauncher/type.png)

### ⏱️ Minuteur (secondes)

Le **Minuteur (secondes)** permet de lancer un décompte précis en secondes, piloté par un démon Node.js dédié (plus réactif que les crons Jeedom à la minute).

![Widget minuteur secondes](/img/plugins/TaskLauncher/chrono_sec.png)

#### Commandes créées automatiquement

| Commande | Type | Description |
|----------|------|-------------|
| `Etat Timer` | Info binaire | `1` = minuteur en cours, `0` = arrêté |
| `Démarrer` | Action slider (1–86400) | Lance le décompte pour la durée spécifiée en secondes |
| `Arrêter` | Action | Stoppe le minuteur immédiatement |

#### Configuration

| Paramètre | Description |
|-----------|-------------|
| **Durée par défaut (secondes)** | Valeur pré-remplie au démarrage du widget |

:::tip Utilisation dans les scénarios
La commande `Démarrer` accepte une valeur en secondes (1 à 86400). Exemple : envoyer `300` pour un minuteur de 5 minutes. La commande `Etat Timer` peut être surveillée pour déclencher une action à la fin du décompte.
:::

:::note Démon requis
Ce type d'équipement nécessite que le démon TaskLauncher soit actif. Le démon démarre automatiquement avec le plugin si Node.js est installé sur le système.
:::

### 🔔 Rappel

Le widget **Rappel** permet de suivre une échéance importante directement depuis le dashboard ou l'application mobile. Il affiche un compte à rebours en temps réel avec un anneau de progression coloré, et peut déclencher des actions Jeedom à l'approche ou à l'atteinte de l'échéance.

![Widget rappel](/img/plugins/TaskLauncher/rappel.png)

L'anneau change de couleur automatiquement selon le temps restant :

| Temps restant | Couleur |
|---------------|---------|
| Plus de 24 h | 🟢 Vert |
| Moins de 24 h | 🟠 Orange |
| Moins de 1 h | 🔴 Rouge |
| Moins de 5 min | 🔴 Rouge pulsant |
| Échu | ⚫ Gris |

Depuis le widget, deux boutons permettent d'agir directement :

- **Snooze +1h** : reporte l'alerte d'une heure
- **Marquer comme fait** : clôture le rappel

#### Configuration générale

| Paramètre | Description |
|-----------|-------------|
| **Titre de la tâche** | Nom affiché sur le widget |
| **Échéance** | Date et heure cible au format `YYYY-MM-DD HH:MM` |
| **Récurrence** | Replanifie automatiquement après l'échéance : Aucune, Quotidienne, Hebdomadaire, Mensuelle, Annuelle |
| **Afficher la date de création** | Affiche ou masque la ligne "Créé le" sur le widget |
| **État** | Permet de remettre un rappel terminé en attente |

:::tip Récurrence
Avec la récurrence activée, le rappel se replanifie automatiquement après chaque échéance — idéal pour les rendez-vous réguliers, paiements mensuels, etc.
:::

#### Alertes avant échéance

Choisissez à quel(s) moment(s) vous souhaitez être alerté avant l'échéance :

| Option | Déclenchement |
|--------|--------------|
| **J−7** | 7 jours avant |
| **J−1** | La veille |
| **H−1** | 1 heure avant |
| **À l'échéance** | Au moment exact (activé par défaut) |

Plusieurs options peuvent être cochées simultanément.

#### Actions à exécuter

Définissez les actions ou scénarios Jeedom à lancer au moment de chaque alerte. Ces actions s'exécutent aux moments définis ci-dessus (J−7, J−1, H−1, à l'échéance).

Exemples : envoyer une notification, allumer une lumière, lancer un scénario.

#### Snooze automatique

Si le rappel est échu et que personne n'a répondu, le snooze automatique reporte l'alerte sans intervention manuelle.

| Paramètre | Description |
|-----------|-------------|
| **Durée** | Délai de report : 30 min, 1 h, 2 h, 4 h, 8 h, 24 h ou 48 h |
| **Maximum** | Nombre de reports automatiques (illimité ou de 1 à 10) |

## 🎛 Commandes disponibles sur le widget

Depuis le widget, plusieurs actions sont directement accessibles.

:::tip Actions possibles
Vous pouvez notamment :

- activer ou désactiver la tâche
- modifier l’heure d’exécution
- modifier les actions
- lancer immédiatement les actions
- définir un lancement différé (enmn)
:::

Sur le **widget alternatif**, il est aussi possible de modifier :

- les heures
- les minutes
- les jours
- l’état d’activation du réveil

:::danger Important
Il ne faut pas activer un équipement entre l’heure différée et l’heure effective, sous peine de déclencher immédiatement les actions prévues.
:::

## 🔗 Utilisation dans les scénarios

TaskLauncher peut être utilisé dans d’autres scénarios Jeedom.

Il est possible par exemple de :

- activer un réveil
- désactiver un réveil
- modifier son heure d’exécution

### Format de l’heure

Le format attendu est le suivant :

```text
0720  →  07h20
1830  →  18h30
```

### Fonctions Jeedom

Vous pouvez aussi utiliser des fonctions Jeedom dans vos scénarios.

```text
#time# + rand(0,100)
```

Dans cet exemple, la tâche sera exécutée à l’heure courante du scénario, plus un délai aléatoire entre 0 et 100.

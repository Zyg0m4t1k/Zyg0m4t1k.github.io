## 0.2 — 2026-09-20

- Widget source : la date affichee indique desormais le dernier changement d'etat d'un moniteur (et non la derniere synchronisation)
- Amelioration de la stabilite lors des mises a jour du plugin

## 0.1 — 2026-08-24

- Version initiale du plugin
- Integration avec Uptime Kuma via API Python (uptime-kuma-api2)
- Architecture double equipement : Sources et Moniteurs
- Demon Python avec polling configurable
- Webhooks temps reel depuis Uptime Kuma vers Jeedom
- Decouverte et synchronisation automatique des moniteurs
- Widget personnalise avec statut, ping, dernier check
- Widget source avec synthese des etats (UP, DOWN, PENDING, MAINTENANCE, UNAVAILABLE)
- Panel desktop avec filtres (statut, source, tags, recherche)
- Panel mobile
- Support multi-sources (plusieurs instances Uptime Kuma)

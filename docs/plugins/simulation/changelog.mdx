- Refactorisation complete du moteur de simulation : remplacement du replay heure-par-heure par des **profils statistiques probabilistes**

- Migration de la base de donnees : `simulation_jeedom` remplacee par `simulation_event` + `simulation_run`
- Suppression des modes `hour` (horaire) et `trigger` (declencheur) : un seul mode **Auto (apprentissage)**
- Familles de groupes : `binary`, `position`, `level`, `color`
- Detection automatique des roles via generic_types Jeedom (`buildAutoGroups`)
- Runtime de simulation persiste en configuration eqLogic
- Daemon migre de **Python** vers **Node.js** ESM (`simulationd.js`)
- Ajout de la page **Sante** avec verification BDD, daemon, Node.js et equipements
- Ajout du mode **dry run** (simulation seule, log uniquement)
- Widget refactorise : journal temps reel avec indicateur d'etat

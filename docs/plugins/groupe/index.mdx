## 📌 Description

Le plugin **Groupe** permet de connaître l'état global d’un ensemble de commandes (ex : plusieurs lumières, volets, alertes)
et d’afficher un **widget** dans vos vues Jeedom avec des **icônes / images** personnalisables.

---

## 📦 Installation

Comme n’importe quel plugin Jeedom :

1. Installer depuis le Market (ou via ZIP)
2. Activer le plugin
3. Aller dans **Plugins → Monitoring → Groupe**

---

## ⚙️ Configuration

### 1) Créer un équipement

Créer un nouvel équipement en cliquant sur **Ajouter**.

![Création équipement](/img/plugins/groupe/groupe5.png)

### 2) Paramètres de l’équipement

#### Ajout des équipements

Deux méthodes sont disponibles pour ajouter des équipements au groupe :

- **Ajout manuel** : cliquer sur le bouton **+** pour ajouter un équipement un par un, puis sélectionner la commande d’état et (optionnellement) les commandes ON/OFF.
- **Ajout automatique par famille** : sélectionner un objet parent (ou « Tous les objets »), choisir une famille d’équipements parmi :
  - Éclairage, Prises et relais, Volets et stores BSO, Thermostats, Serrures, Portails et garages, Détecteurs d’ouverture, Détecteurs de sécurité, Batteries, Commandes génériques

  Puis cliquer sur **Ajouter la famille**. Le plugin détecte automatiquement les équipements correspondants via leurs types génériques et ajoute les commandes d’état et d’action associées. Les doublons sont ignorés.

#### Options

- **Activer les actions** : cocher pour pouvoir piloter les équipements (ON/OFF) depuis le widget.
- **Inverser** : si coché, l’état est inversé (actif quand la commande est à 0).
- **Icône ON / OFF** : icône du widget (FontAwesome) selon l’état du groupe.
- **Image ON / OFF** : image du widget selon l’état du groupe.

> Astuce : vous pouvez choisir **icône** (FontAwesome) ou **image** selon votre rendu préféré.

---

## 🧾 Les commandes

![Commandes](/img/plugins/groupe/groupe6.png)

Le plugin crée automatiquement les commandes suivantes :

- **status** : état global du groupe (1 = au moins un actif, 0 = tous inactifs)
- **statuson / statusoff** : nombre d’équipements actifs / inactifs
- **last** : nom du dernier équipement ayant changé d’état
- **allon / alloff** : actions pour tout allumer / tout éteindre (si les actions sont activées)

## 🧩 Le widget

Exemples de rendu :

![Widget - light](/img/plugins/groupe/light.png)

![Widget - volets](/img/plugins/groupe/volets.png)

![Widget - alerte](/img/plugins/groupe/alerte.png)

Le widget se met à jour en temps réel dès qu'un équipement change d'état.

- Le compteur **X / Y** indique le nombre d'équipements actifs sur le total.
- Le bouton **Tout ON / Tout OFF** permet de piloter l'ensemble du groupe (si les actions sont activées).
- Un clic sur l'icône ou l'image ouvre une modale de détail avec l'état individuel de chaque équipement et la possibilité de les piloter un par un.

![Modale](/img/plugins/groupe/groupe8.png)

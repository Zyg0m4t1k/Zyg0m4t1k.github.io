## 0.3.0 — 2026-09-10

### Nouveautés

* **Serve / Funnel** : adresse HTTPS privée sur le tailnet (Serve) ou accessible depuis Internet (Funnel), avec les autorisations nécessaires côté Tailscale
* **Équipement Self** : commandes dédiées au nœud Jeedom (connecter/déconnecter, état, peers en ligne, exit node, subnet router)
* **Mise à jour Tailscale** : mettez à jour Tailscale directement depuis l'interface
* **Notifications** : messages Jeedom avant expiration des clés (J-14 et J-3) et détection des nouveaux appareils
* **Création automatique** : si l'option est activée, les nouveaux appareils détectés sont créés automatiquement, même sans équipement existant
* **Santé** : bilan du service, du réseau et du routage dans la page Santé de Jeedom et dans les posts Community

### Améliorations

* Meilleures performances et réactivité de l'interface
* Panel mobile accessible aux utilisateurs non-admin
* Restauration automatique des préférences Tailscale lors de la reconnexion
* L'approbation de routes préserve les routes déjà approuvées (exit node, sous-réseaux existants)
* L'état en ligne des appareils est plus fiable
* Le diagnostic reste disponible même quand Tailscale a un problème
* Serve et Funnel affichent le bon état même si d'autres services tournent sur la machine
* La saisie d'un sous-réseau corrige automatiquement l'adresse réseau (ex : `192.168.1.156/24` → `192.168.1.0/24`)

### Corrections

* Rafraîchissement du widget uniquement quand un statut change
* L'approbation de routes est refusée si la liste existante n'a pas pu être lue, pour éviter une perte accidentelle
* Les vérifications de permissions fonctionnent quelle que soit la langue du système

### Documentation

* Présentation des cas d'usage : accès distant, HTTPS privé, accès public, réseau local, supervision
* Section diagnostic : signification de chaque indicateur
* Commandes de l'équipement Self documentées
* Procédure de contournement si le Subnet Router est indisponible
* Notifications et historisation détaillées

### Maintenance

* Migration automatique des commandes depuis les versions précédentes
* Traductions (ES, DE, IT, PT)

## 0.2.0 — 2026-07-28

* Panel mobile

* Amelioration de la latence DERP
* Informations supplementaires depuis l'API Tailscale
* Diagnostic reseau assoupli (UDP, connexion directe)
* Traductions completes (en, de, es, it, pt)

## 0.1.0 — 2026-07-26

* Installation automatique de Tailscale via le script officiel
* Authentification interactive (flux web) et par cle (`tskey-auth-*`, `tskey-client-*`)
* Synchronisation : un equipement Jeedom par noeud du tailnet
* Commandes info : online, IP, IPv6, hostname, OS, derniere activite, connexion directe, DERP, latence, Rx/Tx, LAN, exit node, tags
* Commandes action : Ping Tailscale, Rafraichir
* Auto-actualisation par equipement avec expression cron personnalisable
* Panel Appareils : lister, autoriser/desactiver, tags, routes, expiration cle, details, supprimer
* Tailscale SSH : activer/desactiver depuis le panel
* API OAuth : token cache ~55 min, invalidation automatique au changement de credentials
* Diagnostic complet : service, reseau, UDP, UPnP, DERP, routage, IP forwarding, sante
* Gestion des erreurs CLI : exception sur code retour non nul (sauf commandes de lecture)
* Securite : secrets jamais en argument de processus, audit, double confirmation, chiffrement OAuth
* Nettoyage a la desinstallation : revocation operator, suppression sudoers

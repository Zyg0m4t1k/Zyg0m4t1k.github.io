# Changelog

## 1.0 (beta)

- Version initiale
- Exposition des équipements Jeedom vers Alexa, Apple Home et Google Home via Matter / MatterBridge
- Ajout d'équipements unitaire ou multiple (par plugin)
- Équipement custom (prise virtuelle ON/OFF avec actions paramétrables)
- Page de santé avec diagnostics complets (Docker, réseau, fabrics, synchronisation)
- Commissionnement via QR code
- Vérification automatique du groupe Docker pour www-data
- Bouton redémarrage Apache dans la configuration

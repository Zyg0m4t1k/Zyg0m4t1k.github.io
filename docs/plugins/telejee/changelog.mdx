# Changelog

## 2026-08-06

-Correction de l’enregistrement et du réaffichage des actions multiples sur les logos des chaînes
-Correction de la synchronisation des actions afin de conserver leur structure complète
-Harmonisation de la gestion des actions avec celle du plugin Mode
-Correction des exécutions multiples lors d’un clic sur un logo
-Correction du rafraîchissement automatique qui pouvait vider le widget Programme TV
-Application du même ordre des chaînes sur le Dashboard et la page générale du plugin
-Stabilisation de l’ordre des chaînes sans ordre d’affichage configuré

## 2026-08-02

- Refactoring complet des widgets (Design, Universelle, TV, Paysage, prog) dashboard et mobile
- Nouveaux widgets compacts horizontaux : Design_H, Universelle_H
- Support thème Light (overrides CSS dédiés)
- Ajout jeedom-theme-utils.css pour la gestion des thèmes
- Mise à jour du JS et de la page de configuration
- Nouvelle icône du plugin

## v1.0.0 — 2026-03-16

- 🎉 Version initiale du plugin
- Support Samsung Tizen, LG webOS, Sony Bravia, Android TV
- Commandes : alimentation, volume, navigation, lecture, applications
- Widget dashboard et mobile
- Appairage sécurisé par code PIN
- Wake-on-LAN pour l'allumage depuis l'état éteint
- Polling configurable pour la mise à jour des états
